---
name: Multi-respondent report coverage
description: Requirements for comparative reports across RAOS assessment dashboards.
---

Every multi-respondent RAOS assessment dashboard that produces a report must include a comprehensive overall narrative, domain-level interpretation, and actionable recommendations based on all available respondent records. Keep each respondent's results distinct; compare only matching domains and do not pool or average source scores.

**Why:** The user explicitly requires this for all multi-respondent assessment dashboards, not only the commonly used BASC-3 or BRIEF-2 pages. CDP is also a multi-respondent assessment and has its own dashboard/data path.

**How to apply:** When adding or changing a multi-respondent assessment or report, audit each dashboard/report path (including CDP, generic scored tools, ReMynd Index, product reports, and Chinese Literacy) and verify that separate-source findings, comparison interpretation, and recommendations are visible in the report and its print view.
