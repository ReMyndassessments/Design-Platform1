# Strengthen Your Core programme safeguards

Keep Strengthen Your Core non-diagnostic and school-focused, integrated as an assessment product within the existing RAOS workflow rather than a separate sidebar system. New applications create one shared RAOS inquiry and a pending RAOS case immediately; retain the original application in that case. The standard parent/guardian consent assignment may be sent from the case, but do not create assessment assignments or invitations until consent is verified. Parent/guardian consent is the only consent gate; do not require student assent or show an assent form or checkbox. The pathway uses the enabled core instrument and no more than one approved extension.

Only the designated Strengthen Your Core promotional link for schools may create a Strengthen Your Core inquiry. The general RAOS website portal remains the ordinary inquiry route and must not tag, route, or display those inquiries as Strengthen Your Core.

De-identify intake narratives before any AI call. After parent/guardian consent is verified, use the standard RAOS School/Teacher Referral and Parent Intake forms in the same case. Generate or regenerate the case-level Strengthen Your Core analysis only after both are submitted, combining them with the original school application and saved RAOS interviews/follow-up. Use the non-diagnostic educational criteria, not the generic clinical intake analyzer. AI suggests the core instrument and at most one enabled extension; administrator review is required before assessment assignment.

**Why:** The programme serves minors and handles sensitive educational information. A school inquiry is not parent consent, and an AI suggestion is not professional approval. The user explicitly chose parent/guardian consent alone, one integrated RAOS inquiry/case workflow, and tool recommendations based on the completed standard RAOS intake evidence.

**How to apply:** Keep the ordinary website form and endpoint generic. Only the designated promotional intake may set Strengthen Your Core product/source metadata and create the linked case. Use the standard RAOS consent assignment and verification, then the standard school referral and parent intake assignments. Do not generate the case-level tool suggestions until both responses are complete. Use the existing product dashboard to approve an optional enabled extension before assigning the core tool or extension; once an assessment tool is assigned, lock the extension selection.
