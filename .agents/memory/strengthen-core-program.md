# Strengthen Your Core programme safeguards

Keep Strengthen Your Core non-diagnostic and school-focused, integrated as an assessment product within the existing RAOS workflow rather than a separate sidebar system. New applications create one shared RAOS inquiry and a pending RAOS case immediately; retain the original application in that case. Use the standard RAOS parent/guardian consent assignment; once its completed submission is recorded, assessment assignments unlock automatically. Do not add a separate manual consent-verification step. Parent/guardian consent is the only consent gate; do not require student assent or show an assent form or checkbox. The three required product components are RCEP-CORE, structured classroom observation, and student work/prior-intervention review; outstanding school responses must never block case progress and can be incorporated later.

Only the designated Strengthen Your Core promotional link for schools may create a Strengthen Your Core inquiry. The general RAOS website portal remains the ordinary inquiry route and must not tag, route, or display those inquiries as Strengthen Your Core.

De-identify intake narratives before any AI call. After the standard RAOS parent/guardian consent form is completed, generate or regenerate the case-level Strengthen Your Core analysis whenever the reviewer chooses, using the original school application and whatever RAOS information is available at that time. School/Teacher Referral and Parent Intake responses are optional evidence that can be incorporated later by regenerating the review. Use the non-diagnostic educational criteria, not the generic clinical intake analyzer. AI recommends no more than one enabled extension and drafts practical, provisional Tier 2 intervention targets, supports, observable goals, and progress monitoring; it must identify uncollected classroom/work-sample evidence and must not present the draft as a final plan.

**Why:** The programme serves minors and handles sensitive educational information. A school inquiry is not parent consent, and an AI suggestion is not professional approval. The attached product brief defines the scope as a proportionate Tier 2 learner profile and intervention plan, not a diagnostic or abbreviated comprehensive assessment.

**How to apply:** Keep the ordinary website form and endpoint generic. Only the designated promotional intake may set Strengthen Your Core product/source metadata and create the linked case. Use the standard RAOS parent consent assignment; a completed consent submission unlocks assessment assignments automatically, with no manual inquiry verification. The reviewer may run or rerun the case-level suggestions after consent at any time; never require School/Teacher Referral, Parent Intake, classroom observation, or school work/history responses first. Make all three required core components available through the normal RAOS assignment flow with lead-selected respondents. Include received responses in the analysis and allow later submissions to be incorporated by rerunning it. Missing school evidence must never block review generation, assessment assignment, phase advancement, or reporting; clearly describe its limits when unavailable. Keep the SYC AI path separate from ordinary RAOS clinical intake analysis. Interpret classroom observation and work-sample/history responses descriptively, not as scored tests. Let the AI recommend zero or one enabled extension and a provisional intervention draft. Use the existing product dashboard to approve an optional enabled extension before assignment; once an assessment tool is assigned, lock the extension selection.
